# CyberRange — Integrated Terraform + Ansible Pipeline

## How it works

```
Browser click DEPLOY
      │
      ▼
POST /deploy  ──▶  saves counts to last_config
      │
      ▼
WebSocket /ws  ──▶  terraform apply (streams logs live)
      │
      │  on "Apply complete!"
      ▼
write_dynamic_inventory()  ──▶  generates ansible/inventory/hosts.ini
      │                          from last_config (mirrors Terraform IPs exactly)
      │
      │  sends { ansible_ready: true }  to browser
      ▼
Browser auto-connects WebSocket /ws/ansible
      │
      ▼
WebSocket /ws/ansible  ──▶  ansible-playbook site.yml (streams logs live)
      │
      │  on playbook complete
      ▼
sends { complete: true, success: bool, counts: {...} }
      │
      ▼
Browser shows PIPELINE COMPLETE / FAILED
```

## Running the backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Open http://<your-host>:8000

## One-time Windows VM prep (WinRM)

Run this on each Windows VM via Proxmox console before deploying:

```powershell
winrm quickconfig -q
winrm set winrm/config/service '@{AllowUnencrypted="true"}'
winrm set winrm/config/service/auth '@{Basic="true"}'
netsh advfirewall firewall add rule name="WinRM" dir=in action=allow protocol=TCP localport=5985
```

## Manual Ansible run (bypass UI)

```bash
cd ansible
ansible-playbook site.yml              # full pipeline
ansible-playbook site.yml --check      # dry run
ansible-playbook playbooks/servers.yml # servers only
ansible-playbook playbooks/agents.yml  # agents only
ansible servers,linux_clients -m ping  # connectivity check
ansible windows_clients -m win_ping    # windows connectivity
```
